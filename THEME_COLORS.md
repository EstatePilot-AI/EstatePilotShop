## Usage

Always use CSS custom properties in component styles — never raw hex values:

```scss
.my-component {
  background: var(--surface-card);
  color: var(--content-body);
  border: 1px solid var(--border-default);
}
```

Theme switching is handled by `ThemeService` (`src/app/core/services/theme.service.ts`), which toggles the `body.dark` class. Persistence uses `localStorage` under the key `estate-pilot-theme`.
